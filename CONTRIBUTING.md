# Contributing

Thanks for helping improve Awesome Next.js & Supabase.

This repository is meant to stay practical, focused, and useful for developers building real production apps with Next.js, Supabase, Postgres, RLS, Stripe, App Router, and related SaaS infrastructure.

## What Belongs Here

Good additions are:

- Practical guides with working implementation details
- Debugging playbooks for real production failures
- Architecture resources that explain tradeoffs clearly
- Official documentation for core tools
- Security, RLS, auth, deployment, CI/CD, testing, performance, AI, pgvector, and SaaS resources

## What Does Not Belong Here

Please avoid:

- Generic listicles with no implementation value
- Thin AI-generated filler
- Duplicate resources that cover the same topic without adding depth
- Resources unrelated to Next.js, Supabase, Postgres, SaaS, or production engineering
- Keyword-stuffed descriptions
- Broken links, redirects to spam, or gated pages with no useful preview

## How To Add A Resource

1. Pick the most specific section in `README.md`.
2. Add one bullet with the resource title and link.
3. Use a short, concrete description when the section includes descriptions.
4. Keep formatting consistent with nearby entries.
5. Run a quick link check before opening a pull request.

Example:

```markdown
- [Resource Title](resource-url) - Short explanation of the production problem it helps solve.
```

## Review Criteria

Pull requests are reviewed for:

- Relevance to the repo scope
- Practical implementation value
- Link quality and permanence
- Clear title and description
- No duplicate or low-value entries

Small, focused pull requests are easiest to review.
